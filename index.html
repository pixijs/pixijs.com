PixiJS features

Everything that made PixiJS fast in 2D, now in 3D too.

  • Multi-platform support

    Run your content on desktop, mobile and any other device with a modern browser. Write one codebase and ship it to all of them.

  • Advanced text rendering

    Text renders anti-aliased at native and retina resolutions, so it reads as clearly on the canvas as it does anywhere else.

  • Full scene graph+ Z AXIS

    Organise your objects in hierarchical trees, with parent-child relationships, in two dimensions or three.

  • Tinting & blending modes

    Tint any object and use the Photoshop-style blend modes that designers already know.

  • Asset loader+ glTF

    Load spritesheets, graphics, fonts and animation data, and now glTF and GLB models with their materials, skins and animations.

  • Spritesheet support

    Load a range of spritesheet formats, with support for trimming and rotational packing to fit more sprites on each sheet.

  • Filters & materials+ PBR

    Use the built-in filters or write your own shaders. Meshes get metallic-roughness materials, image-based lighting and point, spot and directional lights.

  • Renderer auto-detect

    Ask for WebGPU and PixiJS falls back to WebGL wherever it isn't available. It handles the switch for you, in 2D and 3D.

  • Easy API

    The API is designed to be easy to learn. It's simple enough for beginners and still gives experienced developers full control.

  • Multi-touch interactivity+ 3D PICKING

    PixiJS tracks multi-touch input, and now ray-picks meshes so they take the same pointer events as your sprites.

  • Accessibility

    PixiJS places hidden DOM elements over accessible objects, so screen readers and keyboard users can reach them. No other WebGL renderer does this.

  • Deploy into apps

    Wrap your project with Capacitor, Electron or Cordova to ship it to app stores and desktops. You can prototype and release with the same code.

ECOSYSTEM

More than a renderer.

  • Filters

    Nearly 40 ready-made filters for any display object: glow, CRT, glitch, ASCII, shockwave and more.

    npm i pixi-filters

  • React

    Write PixiJS scenes as React components.

    npm i @pixi/react

  • Sound

    WebAudio playback, sound sprites and filters.

    npm i @pixi/sound

  • Spine

    Skeletal animation with the official Spine runtime.

    npm i @esotericsoftware/spine-pixi-v8

  • AssetPack

    Pack spritesheets, compress textures and write manifests at build time.

    npm i -D @assetpack/core

  • DevTools

    Inspect your scene graph and textures from Chrome DevTools.

    npm i -D @pixi/devtools

  • CLI

    Start a project from a template, with a bundler set up.

    npm create pixi.js@latest

  • Layout

    Flexbox layout for your containers and sprites.

    npm i @pixi/layout

  • UI

    Buttons, sliders, lists and scroll boxes for in-game UI.

    npm i @pixi/ui
